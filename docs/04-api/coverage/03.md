## Notes for the integration run
- `searchProjects` (`/search/projects`) serves the explore lists of spec 03 AC-32…AC-34 because `/projects` is D5's prefix; D5 may also expose a project list for spec 10. The integration run should check for duplication (see D2 handoff).
- Web numbered pages use the extra `page` query parameter (see handoff request R-1).

**Resolved by the integration run (2026-09-29):** No duplicate: D5 `listProjects` lists only the caller's own projects; public exploring is D2 `searchProjects` (now `optional-user` so Premium viewers get unmasked owners). `?page=` is the shared `PageNumber` parameter (CONVENTIONS §8.1).
