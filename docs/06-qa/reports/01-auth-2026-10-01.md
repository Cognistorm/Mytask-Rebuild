## 11.5 Proposed deviation for the Owner
**DEV-M1: the app has no "back to homepage" link on login and register** (spec 01 "Panel texts and links", last bullet). QA judgement: **acceptable, recommend approval**, for these reasons:
1. In legacy the link appears only on small screens (`block lg:hidden`). It exists because the narrow web layout hides the site header, so the user would otherwise have no way back to the public site.
2. In slice 01 the app's home tab is signed-in only, so a "home" link from a signed-out screen would lead straight back to login.
3. The operating system's back navigation (Android back, iOS swipe) already covers leaving the screen.
Condition: re-check it when the public home arrives in the app (slice 02). If the public home is reachable while signed out, add the link with the same key `t_back_to_homepage`. QA will re-check this in the slice 02 parity report.
