# i18n in the legacy app
- Languages: DB table `languages` (language_code, country_code, is_active, force_rtl, timing locales). Active set cached forever (`supported_languages()`, `app/Utils/Helper/helpers.php:1401-1430`). Production has `ka` and `en` (live site ka default; `?locale=ka|en`). Seeder only seeds `en` (`database/seeders/LanguagesTableSeeder.php`) ⇒ `ka` row added in production.
- Locale selection: `?locale=` query saves to session; otherwise session or `settings_general.default_language`; fallback on error forces `en` (`app/Http/Middleware/SetLocale.php:19-118`). URLs are NOT localized (same URL for both languages) except `/ka/gita`, `/en/gita`.
- UI strings: PHP arrays `lang/{en,ka}/messages.php` (keys `t_*`), `lang/en/dashboard.php` (285 admin keys, en only), `lang/ka/validation.php` (1 key), `lang/vendor/wireui/*`. Accessed via `__('messages.t_x')`. Email subjects/bodies also `messages.t_*`. In-app notifications store the key in DB and translate at render.
- Key counts: en/messages 2,730 entries (2,725 unique, 5 duplicate keys); ka/messages 2,678 (2,675 unique). 59 keys in en missing in ka (e.g. t_admin_approved_unblock_request, t_featured_projects, t_gig_title_validation_*); 9 keys in ka missing in en (e.g. t_bonus_premium, t_paid_premium, t_file_not_allowed). 4 empty values in ka (t_enter_subcategory_slug, t_you, t_recaptcha_apply, t_do_something_im_really_good_at); 0 empty in en. Note: legacy English values are filled (contradicts CLAUDE.md "same convention as old code" of empty en) (Q-031).
- Runtime translation editor: admin `/dashboard/languages/translate/{id}` rewrites `lang/{code}/messages.php` on the server (`app/Livewire/Admin/Languages/Options/TranslateComponent.php:95-230`) ⇒ production lang files may differ from repo (Q-031).
- Content translations (DB, astrotomic/laravel-translatable; locales `['en','ka']`, use_fallback false, property fallback true, fallback `en` — `config/translatable.php:13,52,64,80`): gig_translations(title, description), project_translations(title, description), category/subcategory/childcategory_translations(name, content_top, content_bottom), projects_categories_translation(name), project_skill_translations(name), level_translations(title), page_translations(title, content), blog_article_translations(title, content), attribute_translations, package_translations; plans.name/description/features JSON {en,ka}.
- Content rules: Georgian required for gigs/projects (ka regex Georgian-only), English optional (Latin-only). English locale 404s projects lacking `en`. `GigTranslation`, `Gig::scopeWithEnglishTranslation` (`app/Models/Gig.php:80`).
- Emails: most sent in `config('app.locale')`; renewal email forced `ka`.
- Fonts: FiraGO + BPG css for Mkhedruli.
